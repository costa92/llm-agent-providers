## Directory Purposes

**`openai/`:**
- Purpose: OpenAI provider adapter (chat completions + embeddings + tools).
- Contains: constructor, request/response mapping, SSE stream reader, error mapper, tests.
- Key files: `openai.go` (adapter + stream reader), `options.go` (constructor + `WithX`), `map.go` (request/response translation), `errors.go` (`wrapErr`).

**`anthropic/`:**
- Purpose: Anthropic provider adapter; no embeddings.
- Key files: `anthropic.go`, `options.go`, `map.go`, `errors.go`, plus README documenting the deliberate embeddings gap.

**`ollama/`:**
- Purpose: Local Ollama; *per-model* capability detection for tools and embeddings.
- Key files: `ollama.go`, `options.go`, `map.go`, `errors.go`, plus `tool_strategy.go` (per-family tool parsers) and `embed_strategy.go` (per-model embedding dims).

**`deepseek/`:**
- Purpose: DeepSeek adapter built on the OpenAI SDK; region presets.
- Key files: `deepseek.go`, `options.go`, `map.go`, `errors.go`.

**`minimax/`:**
- Purpose: MiniMax adapter built on the Anthropic SDK; region presets.
- Key files: `minimax.go`, `options.go`, `map.go`, `errors.go`.

**`internal/contract/`:**
- Purpose: Cross-provider fixture-driven conformance suite. Go's `internal` keyword prevents external import.
- Contains: harness (`contract.go`), conformance cases (`generate_test.go`), `goleak` wiring (`main_test.go`), build-tagged live test (`ollama_live_test.go`), JSON fixtures under `testdata/`.

**`internal/contract/testdata/`:**
- Purpose: per-provider JSON fixtures (request assertions + canned response + expected `llm.Response` fields).
- Generated by: `scripts/capture-fixtures-{openai,anthropic,ollama}.sh` against real provider APIs.
- Committed: yes (used by every PR run).

**`docs/superpowers/`:**
- Purpose: design docs (`specs/`) and execution plans (`plans/`) for sub-agent driven development.
- Generated: no — handwritten.
- Committed: yes.

**`scripts/`:**
- Purpose: developer tooling. Workspace bootstrap + fixture capture.
- Not imported by Go code.

**`.github/workflows/`:**
- Purpose: CI definitions. Four workflows (see STACK.md).

**`.planning/codebase/`:**
- Purpose: codebase-map outputs from `/gsd:map-codebase` (this directory).
- Generated: yes — by the mapper agents.

## Naming Conventions

**Files:**
- `<provider>.go` — main adapter file (struct, interface assertions, public methods, stream reader).
- `options.go` — constructor + `WithX` option helpers + `config` struct.
- `map.go` — `toSDKRequest`, `fromSDKResponse`, request/response translation.
- `errors.go` — `wrapErr` and any provider-specific error helpers.
- `doc.go` — package-level godoc (one short paragraph).
- `<provider>_test.go` — unit tests with `httptest`.
- Ollama is the only package with extra files: `tool_strategy.go`, `embed_strategy.go`.

**Directories:**
- One directory per provider, lowercase, no underscores.
- `internal/contract/` mirrors Go's `internal` rule to make the harness import-private.

**Functions:**
- Exported constructors: `New(opts ...Option) (*<Provider>, error)`.
- Option setters: `With<Knob>(...)` returns `Option`.
- Mapping helpers: `toSDKRequest`, `toSDKStreamRequest`, `fromSDKResponse`, lower-camel and unexported.
- Error wrappers: `wrapErr(err)`.

**Types:**
- `<Provider>` struct (exported): `OpenAI`, `Anthropic`, `Ollama`, `DeepSeek`, `MiniMax`.
- Stream readers: `<provider>StreamReader` (unexported), e.g. `openaiStreamReader`, `anthropicStreamReader`.
- Internal config: `type config struct` (unexported).

## Where to Add New Code

**New provider adapter (e.g. `gemini`, `mistral`):**
- Create `gemini/` at repo root.
- Required files: `gemini.go` (struct + interface assertions + Generate/Stream/Info/WithTools), `options.go` (`config`, `WithX`, `New`), `map.go` (request/response translation), `errors.go` (`wrapErr`), `doc.go` (one-paragraph godoc), `README.md`, `gemini_test.go`.
- Pick an existing adapter as the template: openai-shape for SSE chat completions, anthropic-shape for Messages-style APIs, ollama-shape for callback/ndjson local APIs.
- Add interface assertions at file scope (`var _ llm.ChatModel = (*Gemini)(nil)`, etc.) — listing only the interfaces the model can honestly satisfy.
- Bind the model in `New(...)` (K2). Compute capabilities from the model if they vary.
- Translate the SDK stream into typed `llm.StreamEvent` values with stable `Index` for tool calls (K1).
- If the provider should be in the cross-provider conformance suite, add a factory entry to `internal/contract/generate_test.go` (`AdapterFactories` map at `:20`) and drop fixtures into `internal/contract/testdata/<provider>/`.

**New capability on an existing provider (e.g. embeddings on Anthropic):**
- Add `var _ llm.Embedder = (*Anthropic)(nil)` to the assertion block.
- Implement `Embed` and `EmbedDimensions` methods on the struct.
- Update `Capabilities.Embeddings` in `options.go` — set it from the model name when possible (K2 mandate). Static `false` is only acceptable if the package structurally does not implement the interface.
- Add a fixture in `internal/contract/testdata/anthropic/` and a case in `TestEmbed_Conformance`.

**New stream event type (e.g. `EventReasoningDelta`):**
- Land the new `Kind` constant in `llm-agent/llm` first (this repo cannot define new event types).
- Then update each provider's stream reader (`*/openai.go:158-`, `*/anthropic.go:122-`, etc.) to translate the relevant SDK event into the new `llm.StreamEvent.Kind`.

**New region preset for DeepSeek or MiniMax:**
- `deepseek/options.go:46-53` and `minimax/options.go:46-53` are the only places to change. The current placeholder `switch` already accepts new `Region` constants — add them and return the correct base URL.

**New fixture for an existing provider:**
- Use the matching `scripts/capture-fixtures-<provider>.sh` script with valid credentials, then trim/sanitize the captured response. Or hand-author a JSON file following the `Fixture` schema in `internal/contract/contract.go:17-50`.
- Add a `{provider, scenario}` row to the relevant `cases` slice in `internal/contract/generate_test.go`.

**New CI workflow:**
- Add a YAML file under `.github/workflows/`. Set `env.GOWORK: off` (INFRA-02 — see `.github/workflows/test.yml:17`). Follow the `release-precheck.yml` pattern for branch-scoped enforcement.

**New script:**
- Place under `scripts/` with `set -euo pipefail` and the `script_dir`/`repo_dir` derivation already used by the existing scripts.

## Special Directories

**`.planning/codebase/`:**
- Purpose: codebase analysis outputs from `/gsd:map-codebase`. STACK.md, INTEGRATIONS.md, ARCHITECTURE.md, STRUCTURE.md.
- Generated: yes (by the mapper agents).
- Committed: depends on local policy — the directory exists in this repo.

**`internal/contract/testdata/`:**
- Purpose: JSON fixtures driving the conformance suite.
- Generated: optionally — `scripts/capture-fixtures-*.sh` can produce them against real APIs, but they are then committed and read by every CI run.
- Committed: yes.

**`go.work` (if present at parent):**
- Generated by `scripts/workspace.sh`.
- Committed: **no** — `.gitignore:24-25` excludes `go.work` and `go.work.sum`.
- CI sets `GOWORK=off` so workspace files cannot silently affect a build.
